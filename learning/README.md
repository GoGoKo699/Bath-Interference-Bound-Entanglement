# Learning the bath-interference mechanism

[Project overview](../README.md) · [Rivas–Huelga bridge](RIVAS_HUELGA_BRIDGE.md) · [30 milestones](MILESTONES.md) · [Scientific account](../science/README.md)

The project connects two descriptions of the same physical process. A thermal master equation describes how a reservoir moves populations and coherences. A quantum channel, considered together with an untouched reference, describes what that process can preserve or transmit. The central result becomes visible when these descriptions are compared: identical population relaxation can coexist with different entanglement lifetimes.
